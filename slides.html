Rent

Rent

A dashboard that tracks what each memory costs an AI agent to use, and whether it helped answer a question correctly. Memories that cost more than they help get turned off.

Built on EverOS memory and a Snowflake ledger.
The problem

Every memory used in a prompt costs tokens.

AI agents retrieve memories to help answer questions. Each memory adds tokens to the prompt sent to the model. Most systems don't track which memories are actually worth that cost.

Step 3

Whether a memory helped

The model's answer is compared to the known correct answer. Earned is the number of tokens saved when a memory was the reason a question was answered correctly.
